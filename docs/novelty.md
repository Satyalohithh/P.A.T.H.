# Novelty

Status: frozen.

1. **Four-way behavioral taxonomy** with a playful-vs-aggressive boundary,
   which binary fight detectors cannot express.
2. **Dyad-centric feature design**: interpersonal features (approach rate,
   confrontation index, energy ratio, mirroring) computed on tracked pairs,
   not whole-frame aggregates.
3. **Head-height normalization** for proxemic feature scaling, making features
   camera-agnostic.
4. **Explainable risk scoring** with per-factor attribution feeding an
   operator-facing dashboard.
